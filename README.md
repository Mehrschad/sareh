## چرا

**زبانِ فارسی برابر دارد، ولی ما آنها را از یاد برده‌ایم.** «پرماس» به‌جای
«لمس»، «فرنود» به‌جای «دلیل»، «آماج» به‌جای «هدف» — نه از سرِ تعصب، که از سرِ
اینکه واژه‌ای زیبا نباید بمیرد.

**سره پیشنهادگر است، نه سرزنش‌گر.** هیچ‌جا نمی‌گوییم شما اشتباه حرف می‌زنید.
واژه‌ای نشان می‌دهیم و می‌گذاریم خودتان بسنجید.

**و ادعا نمی‌کنیم هر وام‌واژه‌ای جایگزین دارد.** «کتاب»، «قانون» و «عشق» چنان در
بافتِ زبان تنیده‌اند که جایگزین‌سازی‌شان مصنوعی است. آنجا می‌نویسیم «برابرِ
جاافتاده‌ای ثبت نشده» — همین صداقت، اعتبارِ کار را می‌سازد.

این نسخه‌ی ۰٫۱ است: پایه‌ها ایستاده‌اند، ولی هنوز نه ماندگاریِ پایگاه داده
هست، نه صدا، نه هشت گونه‌ی دیگرِ تمرین. آنچه هنوز نیست در
[ARCHITECTURE بخش ۸](docs/ARCHITECTURE.md#۸-آنچه-هنوز-ساخته-نشده) نوشته شده.

## آنچه سره را جدا می‌کند

**بیت‌یاب.** بیتی از شاهنامه یا حافظ با یک جای خالی. کاربر واژه را می‌گذارد و
کلِ بیت روشن می‌شود. یادگیریِ واژه در بافتی که هزار سال دوام آورده.

**نورِ واژه.** پاسخِ درست که دادی، واژه با قلمِ نستعلیق ظاهر می‌شود و رشته‌ای
از نور مسیرِ قلم را در ۶۰۰ میلی‌ثانیه می‌پیماید — انگار خطاط همان لحظه نوشته
باشد.

**هفت‌خان.** به‌جای «واحد ۱، واحد ۲»: هفت قلمرو، هفت نگهبان، روی مسیری اسلیمی.

**اعتیادِ سالم.** بدون شمارشِ معکوسِ اضطراب‌آور، بدون لوت‌باکس، بدون تحلیل‌گرِ
شخصِ ثالث. اگر ۴۵ دقیقه پیوسته کار کنی، خودش پیشنهادِ استراحت می‌دهد. قاعده‌ها
در [ETHICS](docs/ETHICS.md) نوشته و در کد رعایت شده‌اند.

## آغاز

```bash
git clone https://github.com/mehrschad/sareh
cd sareh
make bootstrap
make run
```

برای مشارکت در محتوا به هیچ‌کدام از اینها نیاز ندارید — یک ویرایشگرِ متن بس
است. بنگرید به [CONTENT_GUIDE](docs/CONTENT_GUIDE.md).
